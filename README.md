# Cybersecurity | SOC 

Welcome to my GitHub! I share practical projects, threat-hunting queries, and detection ideas focused on cybersecurity, Security Operations Center (SOC) workflows, and the Microsoft security stack.

My interests include SOC engineering, investigating threats, improving detection coverage, and automating security operations to help teams respond more effectively.

## Areas of Focus

- **Threat Hunting & Detection Engineering:** Using KQL to uncover suspicious behavior and develop actionable detections.
- **Security Operations:** Investigating alerts, connecting evidence, and supporting incident response.
- **Microsoft Security:** Working with Microsoft Defender XDR, Microsoft Sentinel, Microsoft Entra ID, and Microsoft Defender for Office 365.
- **Security Automation:** Using Python, Microsoft Graph, and Azure services to streamline investigations and response actions.

## What I Share

- KQL queries with detection descriptions and MITRE ATT&CK mappings.
- Scripts and automation projects for security operations.
- Investigation approaches and lessons from hands-on learning.
- Labs and examples exploring Microsoft security capabilities.

## Using This Repository

Review each project's documentation for its purpose, prerequisites, configuration, and limitations. Adapt queries and scripts to your environment, validate findings in context, and test response actions before operational use.
